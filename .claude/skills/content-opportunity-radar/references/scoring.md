# Pontuação: probabilidade relativa, Viral Score, penalidades e aceitação

Nada aqui é previsão de viralização. É uma forma de comparar oportunidades entre si e de forçar honestidade na decisão editorial.

## Probabilidade relativa de performance

BAIXA / MÉDIA / ALTA / MUITO ALTA. Justifique com os critérios abaixo, não com sensação.

## Viral Score (0–100)

| Critério | Pontos |
|---|---|
| Recência | 0–15 |
| Tamanho do interesse | 0–15 |
| Curiosidade | 0–15 |
| Impacto | 0–10 |
| Potencial de compartilhamento | 0–10 |
| Potencial visual | 0–10 |
| Força do hook | 0–10 |
| Aderência ao posicionamento | 0–10 |
| Diferenciação possível | 0–5 |
| **Total** | **100** |

### Interpretação

| Faixa | Leitura |
|---|---|
| 0–39 | Fraco |
| 40–59 | Pode funcionar, mas não é prioridade |
| 60–74 | Boa oportunidade |
| 75–84 | Oportunidade forte |
| 85–100 | Prioridade editorial |

O score é uma heurística. Apresente como tal, nunca como previsão matemática.

## Penalidades

Subtraia potencial quando houver:

- assunto saturado;
- ausência de novidade;
- difícil compreensão;
- baixa possibilidade visual;
- necessidade de contexto excessivo;
- pouca relação com o criador;
- fonte duvidosa;
- clickbait necessário para funcionar;
- tema sem consequência;
- baixa diferenciação possível.

## Critérios de aceitação

Uma recomendação só é apresentada como oportunidade forte quando responde com clareza:

- [ ] Existe uma razão para falar disso agora?
- [ ] Existe um público identificável?
- [ ] Existe uma pergunta, tensão ou transformação?
- [ ] Existe um hook possível?
- [ ] Existe uma consequência interessante?
- [ ] Existe algum sinal de interesse?
- [ ] É possível explicar de maneira visual ou narrativa?
- [ ] Existe um ângulo diferente do conteúdo original?
- [ ] O Gabriel pode falar sobre isso sem fingir autoridade inexistente?
- [ ] O conteúdo contribui para o posicionamento dele?

Não precisa cumprir 10/10, mas oportunidades classificadas como ALTA ou MUITO ALTA devem cumprir a maioria.

## Consistência entre score e probabilidade

Score 75+ com probabilidade "baixa" (ou 40 com "muito alta") é contradição: reveja um dos dois. Se o único jeito de a oportunidade subir de faixa é inflar um critério sem evidência, ela não sobe.
